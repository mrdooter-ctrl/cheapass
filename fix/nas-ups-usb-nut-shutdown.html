A power outage while RAID/ZFS or a USB DAS is mid-write can corrupt volumes faster than a bad disk. Worse: buyers keep ordering cheap UPS units only to discover there is no USB data port inside the chassis.

60-second NUT / Synology / TrueNAS checklist

  1. Use the rear USB Type-B Data Port: Ignore top/front USB-A charging slots. If your APC box omitted the lead, grab an ordinary USB-A to USB-B data cable.
  2. Verify OS visibility before touching config: Run lsusb and look for 051d (APC) or 0764 (CyberPower).
  3. Set ups.conf cleanly (fixes CyberPower Data stale resets): 
    [ups]
  driver = usbhid-ups
  port = auto
  pollinterval = 15
  4. Wait 2–3 minutes before triggering shutdown so short grid flickers don't needlessly power-cycle your server.

FAQ

Why won't APC BE425M or BN650M1 shut down my NAS via USB?

Both the BE425M and BN650M1 have ZERO USB data communication capability (BN650M1's top USB-A port is 5V phone-charging only and is explicitly marked unsupported for software shutdown in APC's manual). You need BE600M1/BE850G2 or CyberPower EC/PFC units with a rear USB-B Data Port.

Where do I plug the USB cable into APC BE600M1 or BE850G2?

Plug into the square USB Type-B Data Port on the rear/side panel, NEVER the front/top USB-A charging slot. Newer APC boxes often omit the USB-A to USB-B cable, so keep a standard $6 printer cable handy.

Why does CyberPower throw 'Data stale' warnings in NUT?

CyberPower USB HID controllers sometimes reset if not polled frequently. Add 'pollinterval = 15' inside /etc/nut/ups.conf alongside usbhid-ups (Vendor ID 0764).

When should I pay extra for Pure Sinewave (CP850PFCLCD / CP1500PFCLCD)?

If you run a desktop tower PSU with Active PFC, a Ryzen/Core workstation, or want zero risk of a hard-power trip during battery switchover, pick a PFC Sinewave model.
