Best cheap mini PC for Proxmox

You will run out of RAM long before you run out of CPU.

Proxmox lets one small box run several virtual machines and containers at once. Every VM wants its own slice of memory, so RAM is the spec that decides how far you get. Cores come second.

The picks

  • GMKtec M10: the Proxmox pick on our list. More cores and 24GB of RAM out of the box.
  • GMKtec NucBox M3 Pro: a lot of CPU for the money, but barebone. Good if you already have RAM, or want to buy exactly the amount you need.
  • Beelink EQi Pro: costs more, but has two network ports, so it can also be your router. See mini PC as a firewall.

Before you buy

  • Count your VMs. Add up the RAM each one needs, then add a few GB for Proxmox itself.
  • Check the RAM ceiling on the brand's page before buying. Some boxes take more than they ship with. Some don't.
  • Two SSD slots help. One for the system, one for VM storage, so one failure doesn't take out both. Compare TLC + DRAM drives on our M.2 NVMe SSD variant ladder, or see high-endurance boot drives under $30 and external NVMe enclosures.
  • Keep it cool, wired and headless-ready: see VESA mounts and USB cooling fans, 4K HDMI dummy plugs, 2.5GbE USB adapters, and M.2 heatsinks and precision drivers.
