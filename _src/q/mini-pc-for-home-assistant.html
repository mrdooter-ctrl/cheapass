Cheapest mini PC for Home Assistant

Home Assistant needs less computer than your thermostat thinks.

Home Assistant runs on almost anything. The reason to buy a mini PC instead of a Raspberry Pi is reliability: a real SSD instead of an SD card that wears out under constant writes.

The pick

  • GMKtec NucBox G3 Ultra: the cheapest ready-to-run box on our list. RAM and SSD included. It will run Home Assistant, Pi-hole and a few add-ons without noticing.

Before you buy

  • Already own a Pi 4 or 5? Keep it. Boot it from a USB SSD instead of the SD card and you fix the main problem for the price of a drive.
  • Zigbee or Z-Wave? You'll need a USB stick for the radio either way. Check the box has a free USB port in a sensible place.
  • Want Plex on the same box later? Read the Plex page first. One box can do both.
