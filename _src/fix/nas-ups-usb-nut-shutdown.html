Fix NAS & Linux UPS automatic USB shutdown (NUT BOM)

Don't buy a UPS whose "USB port" only charges phones. Use verified usbhid-ups HID hardware.

{{SEASON}}

A power outage while RAID/ZFS or a USB DAS is mid-write can corrupt volumes faster than a bad disk. Worse: buyers keep ordering cheap UPS units only to discover there is no USB data port inside the chassis.

Disqualified for NAS/NUT auto-shutdown (skip these): APC BE425M (no data port) and APC BN650M1 (USB-A slot is 5V phone-charging only — no PowerChute/NUT data signaling).

60-second NUT / Synology / TrueNAS checklist

  1. Use the rear USB Type-B Data Port: Ignore top/front USB-A charging slots. If your APC box omitted the lead, grab an ordinary USB-A to USB-B data cable.
  2. Verify OS visibility before touching config: Run lsusb and look for 051d (APC) or 0764 (CyberPower).
  3. Set ups.conf cleanly (fixes CyberPower Data stale resets): 
    [ups]
  driver = usbhid-ups
  port = auto
  pollinterval = 15
  4. Wait 2–3 minutes before triggering shutdown so short grid flickers don't needlessly power-cycle your server.
